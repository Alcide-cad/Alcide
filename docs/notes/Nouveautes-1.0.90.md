# ALCIDE 1.0.90

Panneau « Mesurer une distance » :
- en-tête compact sur une ligne : titre, ↗ détacher, × quitter. Le titre n’est plus énorme, les lignes Distance / ΔX / ΔY / Angle sont serrées (panneau 280 × 285 px au lieu de 310 × 500) ;
- déplaçable : glisser l’en-tête. La position est mémorisée pour les mesures suivantes ; ⤓ (ou double-clic sur l’en-tête) le remet dans le coin du dessin ;
- détachable : ↗ l’ouvre dans une fenêtre Windows, comme les autres palettes (déplaçable sur un autre écran, position mémorisée). Il se rouvre détaché à la mesure suivante. « Rattacher » ou la fermeture de la fenêtre le remettent dans ALCIDE ; la mesure continue.

Autres panneaux de mesure vérifiés : la mesure rapide s’affiche directement sur le dessin (pas de panneau), la carte « Mesures de la sélection » est dans les Propriétés ; rien à corriger.

Toujours sans PyMuPDF et sans ODA File Converter embarqué.
